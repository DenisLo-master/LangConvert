# Оставшаяся проверка на macOS

Статус: НЕ ВЫПОЛНЕНО. Этот файл — инструкция проверки, не положительный verdict.
Проверять исходники ветки codex/system-layout-sync, а не прежний build/LangConvert.pkg.
Пользовательская Task и критерии: task.md / AC01–AC18.

1. На macOS с Xcode Command Line Tools выполнить `swift test` и `swift build`.
   Сохранить полный output, macOS/Xcode/Swift версии и commit/diff hash.
2. Закрыть прежний LangConvert, запустить проверяемую сборку `swift run LangConvert`.
   Выдать Accessibility для проверяемого приложения. Убедиться, что не работают
   две копии с одинаковыми hotkeys.
3. В TextEdit и втором редакторе/браузере проверить EN/RU обе стороны, внешнюю
   смену языка до команды, ghbdtn→привет и обратное преобразование; продолжить
   ввод и убедиться, что курсор в конце замены, а источник соответствует результату.
4. Проверить смешанные строки, конечные цифры/пробелы/знаки, уже активную цель,
   третью раскладку вне пары, исчезновение целевого источника, EN/RU варианты
   и вторую доступную не-EN/RU пару. Не менять ожидания по результату проверки.
5. Переключаться между приложениями и окнами одного приложения, включая возврат
   в исходное окно; повторить с системным восстановлением источника документа
   включённым и выключенным. LangConvert не должен восстанавливать свой источник.
6. Проверить смену фокуса/выделения во время операции, частичные результаты,
   неподдерживаемые поля, недоступный Accessibility, повторные команды,
   отказ AX focus notifications и переназначенный системный Control + Space.
7. Проверить native event timing: исходный hotkey не отменяет сам себя;
   новый ввод отменяет оставшееся действие. Проверить AX focus away/back и caret
   readback; это не покрыто тестовой Linux-средой.
8. Проверить tooltip и статус настроек; не должно появляться окно, крадущее фокус.
9. Зафиксировать по каждому AC pass/fail/blocked с наблюдаемым текстом/источником
   и причиной. При failure вернуть developer, затем обновить downstream отчёты.

`swift build` на Linux в этом проекте собирает только LangConvertCore: такой
результат нельзя использовать вместо пункта 1. Изменения не публиковались;
установщик в репозитории содержит прежнюю сборку.
