# Коррекция по прямому указанию пользователя

2026-09-07. Пользователь сообщил, что новая сборка перестала конвертировать
выделение в браузере/Telegram/терминале, и прямо потребовал сохранить исходный
механизм конвертации, добавив только выбор языка в конце. Это актуальное
указание заменяет прежнее требование обязательной AX-проверки замены.

Возвращён исходный Cmd+C / преобразование / Cmd+V с прежними задержками
0.16/0.2 s. Цель берётся из существующего ConversionResult, последнего
однозначного символа. Выбирается конкретный источник без повторного toggle.
AXSelectedText setter/полный AXValue/focus notifications больше не являются
условиями допуска конвертации. Lightweight PID/optional window проверяются
перед вставкой и сменой источника. Буфер сохраняется по типам и восстанавливается
только если его не изменило другое приложение. Повторные команды сериализованы.

Отправка Paste не доказывает принятую редактором вставку: статус говорит
«отправлен на вставку», а не утверждает readback. Это ограничение исходного
способа работы; не выдаётся за положительный native QA.

Отдельно исправлен stale Accessibility статус: при фактическом trusted старое
сообщение запроса доступа заменяется актуальным. Верхний баннер уже обновлялся,
нижняя строка раньше оставалась прежней. Исходный отказ конкретного Mac без
runtime trace не воспроизведён, причина самого разрешения не объявляется известной.

Проверки: 28 core Swift tests, core build, native syntax parse, Python regression,
shell syntax, git diff --check. Требуется macOS build и проверка пользователем.
Исторические Task/handoff описывают прежнюю реализацию; актуальная поправка здесь.
