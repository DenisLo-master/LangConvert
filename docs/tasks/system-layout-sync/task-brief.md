## Исходный запрос и контекст

Пользователь сообщает о непредсказуемой смене языка при переходе между
приложениями и возвращении в окно. Ручное переключение после возврата иногда
даёт неожиданный язык, словно используется старое состояние. Требуется
согласовать LangConvert с фактическим системным источником ввода.

При анализе установлено: текущий switchLocale отправляет Control + Space;
активную раскладку не читает и результат не проверяет. Собственная память
раскладок окон и обработчик восстановления раскладки при смене приложения
в проверенном коде отсутствуют. Причина переключения при смене фокуса на Mac
пользователя не установлена; нельзя выдавать гипотезу за подтверждённый дефект.

Пользователь уточнил: после конвертации выделенного текста нужно сразу
включать раскладку результата, чтобы не переключать её вторым действием.
Пример: пользователь хотел написать по-русски, набрал ghbdtn в английской
раскладке, выделил и преобразовал в привет — дальнейший ввод должен быть
русским. Направление определяется по последнему символу.

## Согласованные требования

1. macOS — единственный источник правды об активной раскладке.
2. Перед каждой ручной командой переключения читать фактический источник
   ввода, а не инвертировать сохранённое локальное значение.
3. Выбирать противоположную раскладку рабочей пары явно и проверять результат.
4. Смена фокуса не должна вызывать восстановление собственной старой раскладки
   LangConvert. Внешнее изменение системного состояния принимается приложением.
5. После успешной замены выделения выбирать целевой источник последнего
   однозначно преобразованного символа результата.
6. Конечные пробелы, цифры и неоднозначные знаки пропускать при определении
   направления; искать назад последний однозначный символ. При отсутствии
   такого символа текущий источник оставлять без изменения.
7. Для смешанного текста направление последнего однозначно преобразованного
   символа определяет дальнейшую раскладку; большинство символов не определяет её.
8. Если нужный источник уже активен, повторное переключение не выполнять.
9. При отсутствии выделения или неуспешной конвертации не менять раскладку.
10. Ошибку выбора источника не выдавать за успешное переключение. Если текст
    заменён, но источник не выбран, различать эти результаты для пользователя.

## Границы и ограничения

- Сохранить существующее преобразование смешанного текста и EN/RU fallback.
- Не менять системные настройки восстановления раскладки документа.
- Не добавлять собственную память раскладок для приложений или окон.
- Дефекты modifier-only hotkeys обнаружены отдельно, но не включены в этот scope.
- Не добавлять индикатор раскладки или иной новый UI без необходимости.
- AppKit/Carbon и фактическое переключение требуют macOS; в текущей Linux-среде
  Swift toolchain отсутствует. Успех локальных Python-проверок не доказывает
  корректность macOS-интеграции.
- Не собирать и не обновлять build/LangConvert.pkg вручную на Linux.
- Публикация, merge и deployment не считаются выполненными или разрешёнными
  только фактом подготовки этого документа.

## Критерии результата

- Системное изменение EN на RU перед командой приводит к выбору EN.
- ghbdtn преобразуется в привет, после успешной замены активна RU.
- привет преобразуется в ghbdtn, после успешной замены активна EN.
- Конечные пробелы и знаки не меняют выбор, установленный последним
  однозначно преобразованным символом.
- Смешанный текст использует направление последнего подходящего символа.
- Уже активная целевая раскладка остаётся активной.
- Неоднозначный текст, отсутствие выделения, отказ разрешения и отсутствие
  целевого источника не вызывают произвольного переключения.
- Возврат между приложениями не запускает принудительное восстановление
  состояния со стороны LangConvert.

## Открытые технические вопросы для полной Task

- Уточнить детерминированное поведение для более двух источников, текущего
  источника вне рабочей пары и исчезновения источника в ходе операции.
- Связать направление преобразования с конкретным ID источника, включая
  fallback и варианты русской/английской раскладки; не угадывать ID по языку UI.
- Определить подтверждение замены выделения и защиту от смены фокуса во время
  операции, прежде чем переключать источник для другого окна.
- Определить ограниченную проверку результата системного выбора и обработку
  ошибки без бесконечных повторов и блокировки интерфейса.
