# Системная раскладка и конвертация

Сверено с исходниками и 28 тестами production ядра. macOS typecheck/runtime
не проверены; установленный пакет не содержит эти локальные изменения.

Система является источником текущей раскладки. LangConvert не хранит
раскладку окна и не восстанавливает её при смене фокуса. Ручная команда читает
TIS source ID, выбирает второй источник рабочей пары и проверяет результат.
Пара сохраняет прежний алгоритм: первая пара разных языков, иначе первые две
доступные раскладки. Вне пары или при недоступном источнике нет угадывания.

Конвертация сохраняет таблицы и возвращает текст с optional target source ID.
Цель определяет последний однозначно преобразованный символ; конечные пробелы,
цифры и неоднозначные знаки пропускаются. Уже активная цель не переключается.

InputOperations сериализует команды через MainActor. MacInputEnvironment
предоставляет живое системное состояние. Для конвертации нужен AX контекст
с элементом, окном, выделением, читаемым текстом и уведомлениями фокуса.
Замена адресная, без буфера обмена; результат и курсор проверяются перед
выбором языка. Ручное переключение не требует доступности текстового элемента:
использует PID и доступную идентичность окна. Единственный вызов выбора
источника происходит до первого async ожидания; далее только подтверждение.

Смена фокуса/новый ввод/отмена прекращают оставшиеся действия. При подтверждённой
замене и неудаче выбора языка возвращается частичный результат. Результат без
readback не объявляется успехом. Снимки текста существуют только во время
операции, не логируются. Системные настройки и память документов не меняются.

Проверки Linux покрывают ядро и внешние сценарии тестовой среды, но не доказывают
поведение AX/TIS. Нужны macOS сборка и реальные сценарии между приложениями,
окнами, с восстановлением источника документа on/off и неподдерживаемыми полями.
